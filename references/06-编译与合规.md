# 06 编译与合规（PDF）

> 产出：`paper/main.pdf`（参赛提交）。写论文用 LaTeX，PDF 用 xelatex 编译。**不再导出 Word（.docx）。**
> 合规检查用 `scripts/compliance_check.py` 自动跑（摘要页数、页码、图表居中、\cite 覆盖、页边距、匿名等）。
>
> 已按 2026-08 国赛 A 题 2024A 复盘补充：**每次改 main.tex 都必须重编 PDF + 重跑合规**，并检查编译退出码与 log。

## 0、每次改动的同步流程（2026-08 复盘）
- 每改一次 `main.tex` 后必须：xelatex 连跑 2 遍 → 重跑 `compliance_check.py`
- **不要只看「生成了 PDF」**：xelatex 非 0 退出码或 `main.log` 里有 `LaTeX Error` 都必须修复后再继续；`\bibitem` 与 `\cite` 的 key 必须严格一致
- **Windows 控制台默认 GBK**：直接跑 `compliance_check.py` 可能因 emoji 报 `UnicodeEncodeError`，先 `$env:PYTHONIOENCODING='utf-8'`（脚本内已兜底）
- **引文编号**：正文/声明需要可见引文编号时，在 tex 中保持 `\cite`，由 PDF 渲染为 [n]。
- 手动改 PDF 不推荐，应改 `main.tex` 重编译；必须直接改时用 PDF 编辑器只做最终微调

## 一、Word 导出（已取消）

> 交付仅需 **PDF + 支撑材料**，**不再导出 .docx / Word 版**。如需 Word 稿供学校模板套用，可另行用 pandoc 转换，不纳入交付口径。


## 二、PDF 编译（两个方案）

### 方案 A：Overleaf（推荐，零安装、对中文/ctex 最稳）
1. overleaf.com → 新建项目 → 上传 `paper/main.tex` + `figures/`
2. 编译器选 **XeLaTeX**
3. 编译通过后下载 `main.pdf` 放回 `paper/`

### 方案 B：本地 xelatex（需有可用的 TeX）
- 工具解析：PATH 上的 xelatex → Modex 内置 `runtime\texlive\miktex\bin\x64\xelatex.exe`
- ⚠️ Modex 内置 MiKTeX 是"未初始化"状态，直接跑报 `fresh TeX installation`。解决：先让 Modex 应用完成一次安装，或运行 `runtime\miktex-setup.exe`，或直接用方案 A
- 命令：`xelatex -interaction=nonstopmode main.tex`（跑 2-3 遍解决交叉引用）
- 编译后检查**退出码与 log**：`if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }`，并 grep `LaTeX Error`；有错即使 PDF 已生成也不算通过

## 三、自动合规检查（scripts/compliance_check.py）

$env:PYTHONIOENCODING='utf-8'
跑 `python scripts/compliance_check.py <paper目录> [main.pdf]`，检查：
1. **摘要 ≤ 1 页**（PDF 第 1 页为摘要，页数校验）
2. **页码**：页脚中部、从摘要页 1 连续编号（检查 tex 的 fancyhdr 配置）
3. **图表全部居中**（每个 figure/table 环境内含 \centering）
4. **每条参考文献至少被 \cite 一次**（\bibitem 数 vs \cite 覆盖）
5. **页边距 ≥ 2.5cm**（tex 的 geometry 配置）
6. **页数**：摘要 ≤1 页；正文（不含参考文献与附录）≤ 30 页，25 页最好（从 PDF 实际页数；参考文献与附录不计入正文）
7. **匿名**：无姓名/学校/指导老师
8. **图表引用完整**：每个 figure/table 有 label 且正文有 \ref
9. **AI 工具使用声明**：参考文献前有「AI工具使用声明」，默认「使用 AI」版（`\section*`）；若使用 AI，支撑材料须含 `AI工具使用详情.pdf`

## 四、合规检查清单（人工复核一遍）

- 页数：摘要 ≤1 页；正文（不含参考文献与附录）≤ 30 页，25 页最好；参考文献与附录不计入正文
- 公式：全部渲染、编号连续、正文有引用
- 图表：全部显示、居中、编号正确、正文有引用、图注中文
- 匿名：全文无姓名/学校/指导老师
- 参考文献：≥8 条、每条正文有 \cite、无官网/组委会条目、真实存在

- AI 声明：参考文献前有「AI工具使用声明」（默认「使用 AI」版）；使用 AI 则支撑材料含 `AI工具使用详情.pdf`（命名固定）
- 文件：main.pdf 可打开、无缺字体
- 提交格式：按官方要求（PDF + 支撑材料）
