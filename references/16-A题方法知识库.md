# 16 A 题方法与算法知识库（速查 + 选型依据）

> 用途：拿到 A 题后，**先判断「这道题在考什么」，再据此选择「先建模、后选数值方法、最后决定要不要智能优化」**。

## 一、A 题整体定位：为什么要先分类再选算法

- A 题 = 本科组**连续系统机理建模赛道**，与 B 题（离散优化）、C 题（大数据分析）并列。
- 本质不是考算法调用熟练度，而是考四项基本功：**物理机理推导、多工况分类逻辑、数值求解设计、结果合理性验证**。
- 核心导向：**重机理、重过程、重落地、反套路**。命题刻意规避教材/培训里的标准化例题，不存在一套万能模板。
- 一句话：**不是先想「套什么算法」，而是先想「物理过程到底怎么发生」**。算法是工具，不是建模本体。
- 主线路线（A 题通用解法）：
  `读题/机理分析 → 几何与运动学建模 → 判定条件构造 → 数值仿真 → 参数优化 → 必要时再引入智能优化`

> **选型铁律**：能把变量数压到较低、约束写得清楚、目标函数可直接计算 → **优先用数值搜索 / 数学规划 / 分阶段优化**；只有高维、非凸、目标依赖仿真、局部最优多时才考虑智能优化。

## 二、四大核心题型 → 对应方法包与算法选型

A 题近十年稳定为四大题型（命题组刻意错开，每道题都要做个性化拆解）。

### 题型 1：几何关系与刚体运动类

- 代表：2024 年《无人机协同投放烟幕的路径规划》、2023 年《无人机遂行编队飞行中的纯方位无源定位》。
- 核心考察：平面坐标变换、碰撞/相交判定、多工况分类讨论、运动轨迹建模。
- 特征：**无复杂微分方程，但极度考验逻辑严谨性与算法可复现性**。
- 常用方法：
  - **线段相交判别法**：两两枚举边线，联立直线方程求交点；缺点是分支极多（平行/重合/端点接触/线段区间约束十几种边界工况），易遗漏场景、稳定性差。
  - **面积判别法（命题组推荐）**：取一矩形全部顶点，计算顶点与另一矩形四顶点围成的 4 个三角形面积之和——总和等于矩形面积则顶点在图形内部，大于则在外。**无需额外边界判断，逻辑极简、稳定可复现**。
- **判据**：分辨率判据要写成标准化数学公式 + 完整算法步骤；多工况（如直行/两段圆弧调头共多类工况）必须配套**明确的切换判定条件**，不能只罗列分段公式。
- 进阶：优先做**几何化简**——选合适坐标系、把轨迹表达成标准形式、把判定转成距离/角度/区域约束，先降维再数值求解。

### 题型 2：常微分方程 + 刚体动力学类

- 代表：2019 年《高压油管的压力控制》、2022 年《波浪能最大输出功率设计》。
- 核心考察：物理机理抽象、**耦合常微分方程组**构建、刚性系统数值求解、动力学参数优化。
- 常见坑：
  - **坐标体系混淆**：以静平衡位置为原点时，重力/浮力/弹簧静弹力已抵消，方程只保留波动附加项，**不要重复加重力**；以海面固定点为原点时则必须完整包含所有受力项。两套模型只差坐标平移，周期/速度结果一致。
  - **自由度建模错误**：误把刚性连接的两个刚体当成 6 自由度独立刚体；正确做法是用拉格朗日方程整合平动/转动动能 + 势能，得到**5 维二阶耦合 ODE**，再转成**10 维一阶方程组**数值求解。
  - **求解器选型失误**：刚性系统用显式 RK（如 ode45）计算极慢甚至发散；必须用**隐式刚性求解器**（ode15s / scipy 的 `solve_ivp(method='BDF'/'Radau')`）。
- 加分项：对线性化系统做**特征值分析**，证明齐次解指数衰减、收敛到周期稳态；优化平均功率时**舍弃初始瞬态波动、只取稳定周期段**计算。

### 题型 3：偏微分方程 + 场分析类

- 代表：2018 年《高温作业专用服装设计》、2020 年《炉温曲线》（+ 2011 年重金属污染为半道）。
- 核心考察：抛物型 PDE 建模、边界条件选取、多层介质交界面条件、有限差分求解。
- 关键点：
  - **控制方程**：温度场统一用傅里叶热传导定律，构建一维/二维非稳态热传导方程。
  - **边界条件**：约 70% 队伍误用第一类 Dirichlet（直接给边界温度）；工程实际高温环境与材料表面是**对流传热**，应用**第三类 Robin 边界（牛顿冷却定律）**。
  - **多层交界面**：需同时满足「温度连续」与「热流密度连续」（由傅里叶定律推导，**不是温度导数连续**）。这是本科教材外的核心区分点，写对可直接进一等奖候选池。
  - **数值格式**：显式有限差分有严格稳定性步长约束（空间步长要到微米级才稳、成本极高）；推荐**隐式后向差分格式，无条件稳定、可用较大步长**，效率提升数十倍。
  - **高效求解**：一维热传导离散后是**三对角稀疏矩阵**；用通用求逆是 O(n³)，迭代优化时致命；标准解法是**追赶法（托马斯算法）O(n)**，效率提升两个数量级，是评审关注的求解亮点。

### 题型 4：参数标定 + 高维反演优化类

- 代表：2017 年《CT 系统参数标定及成像》。
- 核心考察：物理衰减模型、**高维反问题解耦**、最小二乘拟合、误差分析。
- 核心矛盾：高维参数（185 个待标定参数）直接全局寻优，**可行域极度稀疏**，随机采样/启发式几乎无法收敛。不能盲目用 GA/PSO 硬算。
- 标准思路（**分层解耦、分步标定**，把高维拆成多个 ≤3 变量的低维子问题）：
  1. **几何基准校准**：利用圆/椭圆模板投影特征锁定基准旋转角，把 0~180° 大范围搜索压缩到 ±1° 极小邻域。
  2. **无旋转参数标定**：先求与旋转角无关的射线间距、初始偏移量，化为 3 变量低维优化。
  3. **旋转中心求解**：通过坐标变换转成三阶超定线性方程组，**最小二乘解析求解，无需迭代**。
- 常见失分：只用 3~5 组数据标定（浪费样本降噪作用）；混淆离散像素与连续射线模型直接套连续几何公式（角度偏差可达 30%）。

## 三、算法适用场景速查表（每个算法适合解决什么问题）

> Python 为主（本 skill 求解默认 Python），括号内为 MATLAB 对应函数作为对照。

### 1. 方程求根 / 临界时刻
| 方法 | 问题 | Python 实现 | 适用 |
|---|---|---|---|
| 二分法 | 单调区间内求单根 | `scipy.optimize.bisect` | 平衡点、临界时刻、碰撞/达标时刻；稳健 |
| 牛顿法 / 割线 | 单根、局部收敛快 | `scipy.optimize.newton` | 函数光滑、有好的初值 |
| 通用求根 | 方程组 / 非线性多根 | `scipy.optimize.fsolve` | 多变量非线性方程组 |

### 2. 线性 / 非线性方程组
| 方法 | 问题 | Python 实现 | 适用 |
|---|---|---|---|
| 高斯消元 / LU | 稠密线性方程组 | `numpy.linalg.solve` | 离散化后的代数方程组 |
| 迭代法 / 稀疏求解 | 大规模稀疏、三对角 | `scipy.sparse.linalg.spsolve`（或手写追赶法） | PDE 离散后的三对角/带状系统，O(n) |

### 3. 常微分方程数值解（时间演化）
| 方法 | 问题 | Python 实现 | 适用 |
|---|---|---|---|
| 欧拉法 | 一阶、精度要求低 | `scipy.integrate.solve_ivp` | 非刚性、快速原型 |
| 四阶龙格-库塔 RK4 | 非刚性、精度高 | `solve_ivp(method='RK45')` | 轨迹/温度/浓度/姿态演化；非刚体 |
| **隐式刚性求解器** | 刚性系统（时间尺度差异大） | `solve_ivp(method='BDF'/'Radau')` | 2022 波浪能、耦合刚体动力学；**必须用隐式** |
| 变步长自适应 | 多尺度、需效率 | `solve_ivp`（自适应步长） | 轨迹仿真、瞬态 + 稳定段 |

### 4. 偏微分方程数值解（时空耦合）
| 方法 | 问题 | 说明 | 适用 |
|---|---|---|---|
| 显式有限差分 | 时间推进简单 | 稳定性受限（步长极小、成本高） | 非稳态问题临时验证；不推荐主解 |
| **隐式有限差分（后向）** | 无条件稳定 | 可用较大时间/空间步长 | 2020 炉温、2018 高温服；**推荐主解** |
| Crank-Nicolson（CN） | 二阶精度 + 稳定 | 显示+隐式加权 | 热传导、扩散中场分析 |
| 追赶法（托马斯） | 一维三对角 | 复杂度 O(n) | 一维热传导，配合隐式格式 |

### 5. 优化方法（最常考）
| 方法 | 问题 | Python 实现 | 适用 |
|---|---|---|---|
| 枚举 / 网格 | 低维、有限候选 | 手写循环 / `itertools` | 变量少、解空间可穷举；解释性强 |
| 分层 / 变步长搜索 | 中低维、目标单调 | 手写 | 高维问题解耦后的子问题；比暴力优 |
| 二分 / 牛顿 | 单变量单调可微 | `brentq` / `minimize_scalar` | 单参数优化 |
| 非线性规划 | 约束明确、可解析 | `scipy.optimize.minimize(method='SLSQP'/'trust-constr')` | 2023 定日镜（布局+效率）、硬约束优化 |
| 最小二乘 | 参数标定、拟合 | `scipy.optimize.least_squares` | 2017 CT 标定、2020 热传导参数反演 |
| **遗传算法 GA** | 高维、非凸、离散/组合 | `scipy.optimize.differential_evolution` / 自写 | 多机协同、调度、顺序决策、多局部最优 |
| **粒子群 PSO** | 连续高维、非凸 | 自写 / `pyswarms` | 高维连续参数搜索（2025 烟幕协同） |
| **模拟退火 SA** | 组合/离散、大邻域 | 自写 / `scipy.optimize.dual_annealing` | 组合优化、路径、时序决策 |

> 结论：**智能优化是加分工具，不是起手式。** 先把机理/几何/约束搭好，再决定是否需要智能优化做后段搜索。

### 命题趋势
1. 背景始终偏**物理/工程/控制**，不是纯数据、纯经验决策。
2. 正在从「单系统参数求解」走向「**多因素协同优化**」（2025 明显：多主体、多时刻、多约束、时空联合）。
3. 近两年对**几何与运动学**要求更强，几何化简成为「模型化简的第一抓手」（2024 碰撞、2025 遮蔽）。
4. 2020–2024 大多数 A 题主体 = **机理建模 + 数值仿真**，变步长搜索/枚举/牛顿/ODE 求解/局部优化/几何判定往往就够；2025 更值得上智能优化。

## 五、何时用智能优化（实战判断标准）

若 A 题满足以下特征，才更可能需要智能优化辅助：

- 变量数量明显增多；
- 同时存在**时间、空间、顺序**三类决策；
- 目标函数**只能通过仿真得到**（无解析式）；
- 可行域**很不规则**；
- **局部最优很多**。

若不满足（变量少、约束清晰、目标可直接算），则优先用：
`机理建模 → 常规数值方法 → 变步长搜索 → 局部优化 / 数学规划`。

**更稳妥的路线**（2025 类题）：
`运动学/几何/遮蔽判定搭好模型 → 把协同问题转成优化问题 → 最后再用 GA/PSO/SA 做高维搜索`。智能优化用于**高维参数搜索**，而不是替代前面的机理建模。

## 六、评阅核心维度与高频误区

### 评分五维
1. **模型完整性（基础门槛）**：微分方程类必须带完整定解条件（初值+边界）；优化类必须**同时给目标函数与全部等式/不等式约束**；多工况类必须覆盖全部有效场景并有切换判定准则。缺失即降档。
2. **机理严谨性（≈40%）**：非通用模型必须完整展示推导过程；简化假设要有工程合理性；边界/交界面/受力分析符合行业规范。
3. **求解合理性（≈30%）**：数值方法匹配问题特征（刚性→隐式、稀疏→追赶法）；高维优化必须有**解耦降维**，禁止盲目套启发式；必须说明算法参数、离散步长、终止条件依据。
4. **结果有效性（≈20%）**：配套可视化与定量分析；含误差/灵敏度/稳定性分析；符合物理常识。
5. **理论创新性（加分）**：稳定性/收敛性/唯一性证明；针对问题的专用简化算法；可落地改进方案。

### 高频共性误区（考试失分主因）
1. 重算法套用，轻机理推导（本末倒置）。
2. 重结果输出，轻过程说明（复现性为零）。
3. 重形式完整，轻物理合理（随意设边界/假设）。
4. 重全局硬算，轻拆解降维（高维盲目暴力/启发式）。
5. 混淆连续与离散体系（直接用连续公式套离散像素/采样）。

## 七、与 skill 流程的结合点

- **步骤 1（赛题分析）**：用本文件判断「四大题型中属于哪类」，据此在 `PROBLEM_ANALYSIS.md` 里写本质归类与核心矛盾；优化题按 `references/15` 写出标准「max + s.t. + 大括号」。
- **步骤 2（建模求解）**：按「解析基线 + 数值仿真 + 约束优化」三层结构规划；查本文件第三、四节选数值方法；高维优化必须写解耦降维（见题型 4），并登记到 `MODELING_REPORT.md` 第 0 节。
- **步骤 3（编程实现）**：按表格选 Python 函数（`solve_ivp`、`minimize`、`least_squares`、`spsolve` 等）；刚性/稀疏/追赶法优先；结果写入 `resultN.xlsx` 供步骤 8 溯源。
- **步骤 8（审计）**：评阅五维对应 `solution_audit.py --mode deliverable` 与 `--mode optimization` 的检查项；高维解耦、硬约束进搜索、代理保真度都要能对上。
