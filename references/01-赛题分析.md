# 01 赛题分析

## 目标
把一道 72 小时的赛题变成可执行的建模方案，产出 `PROBLEM_ANALYSIS.md`。

## 审题流程
1. 通读全文两遍：第一遍抓背景与目标，第二遍抓数据、约束、待求量
2. 区分题目类型：
   - A 题（连续/物理类）：物理机制驱动，常含微分方程、控制方程、边界条件
   - B 题（离散/优化类）：路径/调度/决策，组合优化
   - C 题（数据类）：大数据分析、统计建模
3. 若为 A 题，按下方"A 题专项"深入分析

## PROBLEM_ANALYSIS.md 结构
1. 问题重述：一句话目标 + 子问题拆解
2. 问题类型判断与理由
3. 关键假设（每条标注对结果的影响）
4. 已知量与待求量清单（数据表）
5. 物理机制分析（A 题）：守恒律/平衡方程/经验公式/主导过程
6. 初步求解思路（2-3 条路线 + 取舍）
7. 风险点与难点（数据缺失、非线性、计算量、量纲）

## A 题专项
- 识别支配过程的物理规律：守恒（质量/能量/动量）、平衡、扩散、波动、增长
- 写出候选控制方程（ODE/PDE）与定解条件（初值/边值）
- 判断参数来源：题给数据反演 / 文献经验值 / 需要估计
- 预估数值求解难度：刚性、非线性、高维 → 决定用解析近似还是数值
- 常见 A 题主题：热传导、流体/扩散、种群动态、振动、电路、材料应力、传染病、物理实验标定
