# AI 工具使用详情

> 依据《全国大学生数学建模竞赛人工智能工具使用规定》，本参赛队在竞赛过程中使用了 AI 工具，详细使用情况如下。本文件最终需导出为 **`AI工具使用详情.pdf`**（文件名固定）并放入支撑材料 `materials/`。

## 1. 所用 AI 工具名称、版本或型号
- 工具：DeepSeek
- 版本/型号：DeepSeek-V4-Flash（`deepseek-v4-flash`）

## 2. 具体使用目的和环节
| 环节 | 用途 | 说明 |
|---|---|---|
| 赛题分析 | 题意拆解、已知/待求梳理 | 快速形成问题重述与技术路线图初稿 |
| 建模 | 公式推导方向、模型选型建议 | 提供机理建模思路与守恒/平衡方程框架 |
| 编程 / 求解 | 代码框架、算法实现与调试 | 生成可独立运行的 problemN.py 骨架，辅助定位报错 |
| 论文写作 | 语言润色、排版、图表说明 | 摘要 / 正文措辞润色，图表规范整理 |

## 3. 主要提示方式与使用过程说明
- 主要提示方式：将赛题 PDF 提取文本与原始数据一并给出，按子问题逐问下达任务；要求给出可独立运行的 `problemN.py`、按功能命名的共享模块（如 `data_io.py`）；示意图先给节点 / 连线清单生成 Draw.io 草图，再人工调整。
- 使用过程（典型交互摘要）：
  1. 用户：「这是 2026 年 A 题，第一问需建立……，请给出建模思路与可独立运行的 problem1.py。」
  2. 模型：给出建模思路、公式框架与示例代码。
  3. 用户：「按此思路把 problem1.py 拆成独立可运行，公共函数放 data_io.py，并约定 result1.xlsx 的列与灵敏度分析。」
  4. 用户：「把摘要润色得更简洁，检查公式编号与图表引用。」

## 4. 对 AI 输出的采纳、人工修改和核验情况（语言润色除外）
- 采纳情况：模型给出的建模框架、公式方向、代码骨架、示意图结构作为起点采用。
- 人工修改：核心模型假设、决策变量、目标函数、约束条件由参赛队依据题目重写；所有数值结果（6~8 位小数）由参赛队自写求解代码跑出，AI 仅提供思路与框架；流程图 / 示意图骨架人工在 Draw.io 中调整布局、文字与配色。
- 核验情况：每个关键数字在 resultN.xlsx / 运行输出中可溯源；用另一引擎或独立实现交叉验证重算；公式逐条代入做量纲 / 量级检查；图表与结果一一对应。语言润色除外。

> 说明：核心建模与分析由参赛队主导；AI 参与内容均已逐项人工审查与核实。
