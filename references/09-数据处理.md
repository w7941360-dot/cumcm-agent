# 09 数据处理（赛题 PDF + 原始数据 xlsx）

> 比赛开始第一步：把用户上传的赛题 PDF 和原始数据表格变成可分析的材料。用 `scripts/process_inputs.py` 一键完成。

## 一键处理命令
```
python scripts/process_inputs.py <工作区> <赛题.pdf> [附件1.xlsx 附件2.xlsx ...]
```
产出：
- `problem/<赛题名>_提取文本.txt` — PDF 全文（分页）
- `problem/DATA_PROFILE.md` — 每个 xlsx 的数据探查报告
- `data/` — 原始数据副本

工具解析：PDF 提取按 PyMuPDF(fitz) → pypdf → PyPDF2 依次尝试；xlsx 用 openpyxl（Modex 内置 Python 与 Anaconda Python 都已验证可用）。

## PDF 赛题
- 正常情况：提取全文后逐页通读，记录题目要求、已知量、待求量、单位、约束
- ⚠️ **扫描版/图片版**（脚本提示提取不到文字）：
  - 用 OCR 工具（Tesseract / Word 的 PDF 转文字 / 在线 OCR）
  - 或把每页转成图片，用视觉模型/人工读取
- **PDF 里的示意图、数据表、公式也是信息源**：文字提取会丢失布局，重要公式和图表要对照 PDF 原文核对

## xlsx 数据
### 先读 DATA_PROFILE.md
- sheet 数量、每表行列数、列名、缺失量、类型分布、数值 min/max/mean
### 数据清洗（在 `data/processed/` 输出，原始文件不动）
- 缺失值：先记录数量，再决定删除/插值/填默认，**每一步说明理由**
- 单位统一：混用单位（米/千米、小时/天、摄氏/华氏）先统一，写进数据字典
- 异常值：与物理常识对比（如温度超物理范围、负浓度），**标记而不是直接删**
- 时间/日期：统一格式；检查是否按时间排序、有无跳变
### 数据字典
- 每个 sheet 每列写清：含义、单位、取值范围、来源（题给/附件/文献）
### 与建模衔接
- 区分自变量 / 因变量 / 题给固定参数
- 哪些数据用于参数辨识、哪些用于模型验证
- A 题尤其注意：数据是否满足控制方程的定解条件（初值/边界）

## 数据约定
- `data/` 里的原始文件只读；清洗/处理脚本输出到 `data/processed/`
- 每个处理步骤在代码注释或 RESULTS.md 里写清，保证可复现（配合步骤3）
