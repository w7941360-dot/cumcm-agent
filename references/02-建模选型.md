# 02 建模选型

## 模型分层（A 题优先机理）
- 机理模型：守恒方程 → ODE/PDE → 数值求解
- 参数辨识：最小二乘 / 极大似然 / 贝叶斯 / 网格搜索；评价拟合优度
- 数据驱动（仅辅助）：回归、插值、机器学习 —— 机理不明确时补充，A 题不要全程黑箱
- 优化：含决策/设计变量时 → 线性规划/非线性规划/启发式

## A 题共同规律
- A 题优先是**机制题**，不是模型名堆砌题：先建立坐标、时间、单位和物理量，再选算法
- 几乎都需要「**解析基线 + 数值仿真 + 约束优化**」三层结构
- 图表要展示机制：曲线、轨迹、空间布局、约束可行性、优化前后对比
- 得分点通常在「模型是否贴合物理过程」和「结果是否可验证」，不是算法复杂度

## A 题默认解题顺序
1. 物理对象拆解：明确运动对象、控制变量、状态变量、观测量和目标量
2. 坐标与时间轴：统一坐标系、时间零点、单位、方向和边界
3. 解析基线：写出简化情形下的公式或可手算方案
4. 仿真模型：把状态演化、几何关系或能量转换写成可复现代码
5. 优化模型：定义决策变量、目标函数、硬约束和软约束
6. 可行性检查：检查速度、温度、功率、伸缩量、碰撞、覆盖或遮挡等约束
7. 敏感性分析：扰动关键物理参数和优化变量，观察结果稳定性
8. 论文表达：按「物理机制 → 数学表达 → 算法求解 → 约束检查 → 结果解释」顺序写

## 三类高频方法包

### 工程过程控制（2020 炉温曲线、2022 波浪能）
- 基线：一阶惯性、分段线性、能量守恒或简化微分方程
- 主模型：ODE/差分方程、参数拟合、数值积分、单/多参数优化
- 必查：参数单位、边界条件、采样间隔、峰值、持续时间、平均功率
- 常见错误：只拟合曲线不解释物理量；优化结果违反工艺窗口或功率定义

### 几何光学与曲面设计（2021 FAST、2023 定日镜场）
- 基线：理想几何曲面、单点反射、无遮挡效率
- 主模型：坐标变换、曲面拟合、光线追踪、遮挡阴影、布局优化
- 必查：坐标系、法向量、反射定律、角度单位、边界范围、机械约束
- 常见错误：没有统一坐标系；只算效率不查遮挡或伸缩量可行性

### 轨迹覆盖与避碰优化（2024 板凳龙、2025 烟幕干扰弹）
- 基线：单对象轨迹、单时间段覆盖、规则速度方案
- 主模型：运动学方程、碰撞/遮蔽判定、区间合并、多阶段优化、启发式搜索
- 必查：时间离散步长、速度范围、间隔约束、覆盖半径、碰撞距离、区间重叠
- 常见错误：用离散采样直接声称最优；遮蔽/碰撞判定没有几何解释
- 多弹/多对象问题：单对象最优只能作基线；必须最大化并集覆盖并惩罚重叠；时序间隔等是**硬约束**不是后处理格式问题；搜索方案写「固定随机种子得到的可行优选方案」，不写「已证明全局最优」

## A 题数值方法库
| 问题 | 方法 |
|------|------|
| ODE 初值问题 | RK4 / scipy.solve_ivp |
| 一维抛物型（热传导/扩散） | 隐式差分（Crank-Nicolson） |
| 双曲型（波动/对流） | 特征线 / 迎风格式，注意 CFL 条件 |
| 椭圆型（稳态场） | 有限差分松弛 / 直接解线性系统 |
| 复杂几何/材料 | 有限元（如 FEniCS）或简化网格 |
| 随机过程 | 蒙特卡洛、随机微分方程 |
| 空间离散 | 有限差分 / 有限体积，检查稳定性与收敛 |

## 必做分析（A 题得分关键）
1. **灵敏度分析**：关键参数 ±10%~±50% 扰动，观察结果变化；单参数扫描或 Sobol
2. **稳定性/收敛性**：网格加密、时间步长减半，验证结果不漂移
3. **模型验证**：与解析解对照 / 与题给数据对比 / 极端情形检验
4. **量纲一致**：每个方程检查单位

## 建模原则
- 假设明确、可辩护；先简后繁，先保证可解再逼近真实
- 每个模型写清：输入、输出、参数、适用范围
- 明确模型局限性（评审常考）
