# 03 编程实现

## 工程规范
- Python 3 + numpy/scipy/pandas/matplotlib；结构清晰、函数化、注释关键公式出处
- `code/` 下：`main.py`（一键复现主流程）+ `utils.py`（通用函数）+ 各模型脚本
- 固定随机种子 `np.random.seed(0)`，结果与图表可复现
- 数值计算保存中间结果（npy/csv），避免重复跑长任务

## 数值实现要点
- ODE/PDE 求解：选稳定格式，检查 CFL/收敛；scipy.integrate 设 rtol/atol 并验证
- 线性系统：注意条件数，病态时用正则化或提高精度
- 大量实验：写循环 + 进度日志 + 结果汇总表

## 结果可信度校验（每项都过）
1. **Sanity**：数量级合理吗？单位对吗？极端输入下行为合理吗？
2. **Consistency**：结果内部自洽（守恒量守恒、边界条件满足、不同方法结果一致）
3. **Physical**：物理约束满足（非负、有界、能量/质量守恒）
4. **Prediction**：外推一段是否合理？参数扰动方向是否符合直觉
5. **Evaluation**：与数据/解析解对比的误差指标（MAE/RMSE/相对误差）
