# 06 编译与合规（PDF + Word）

> 产出：`paper/main.pdf`（参赛提交）+ `paper/main.docx`（Word 版）。写论文用 LaTeX，PDF 用 xelatex 编译，Word 用 pandoc 从 LaTeX 导出。
> 合规检查用 `scripts/compliance_check.py` 自动跑（摘要页数、页码、图表居中、\cite 覆盖、页边距、匿名等）。

## 一、Word 导出（pandoc：LaTeX → docx）— 已实测可用

### 工具解析（按顺序找 pandoc）
1. PATH 上的 `pandoc`（如 Anaconda 自带 2.12）
2. Modex 内置 runtime：`D:\modex\Modex-MH-Agent\runtime\pandoc\pandoc.exe`（3.7，仅当已安装 Modex）
3. 都没有 → 提示安装：`winget install JohnMacFarlane.Pandoc` 或 `conda install -c conda-forge pandoc`

### 命令
```
cd paper
pandoc main.tex -o main.docx --resource-path=. --resource-path=../figures
```
- `--resource-path`：让 pandoc 能找到 figures/ 下的图片并**嵌入 docx**（保证 Word 打开有图）
- ⚠️ **Word 必须嵌入 PNG 图**：figures/ 下每张图都要有 PNG 版（LaTeX 用 PDF 矢量版，Word 用 PNG）；若只有 PDF，pandoc 可能嵌入不了，需先转 PNG
- 数学公式自动转 Word 原生公式（OMML），可编辑

### 转换注意事项
1. **TikZ/PGF 内联图不转换**：架构图/流程图必须用外部图片文件（步骤5 已约束）
2. **自定义命令/宏可能丢失**：尽量只用标准 LaTeX；自定义 \newcommand 若影响内容先在 tex 里展开
3. **页数会变**：Word 排版与 PDF 不同，导出后在 Word 里单独核对页数上限
4. **中文字体**：docx 用 Word 默认字体；学校模板有字体要求则导出后套模板
5. **附录/目录**：如需目录加 `--toc`；附录代码用表格+行号

## 二、PDF 编译（两个方案）

### 方案 A：Overleaf（推荐，零安装、对中文/ctex 最稳）
1. overleaf.com → 新建项目 → 上传 `paper/main.tex` + `figures/`
2. 编译器选 **XeLaTeX**
3. 编译通过后下载 `main.pdf` 放回 `paper/`

### 方案 B：本地 xelatex（需有可用的 TeX）
- 工具解析：PATH 上的 xelatex → Modex 内置 `runtime\texlive\miktex\bin\x64\xelatex.exe`
- ⚠️ Modex 内置 MiKTeX 是"未初始化"状态，直接跑报 `fresh TeX installation`。解决：先让 Modex 应用完成一次安装，或运行 `runtime\miktex-setup.exe`，或直接用方案 A
- 命令：`xelatex -interaction=nonstopmode main.tex`（跑 2-3 遍解决交叉引用）

## 三、自动合规检查（scripts/compliance_check.py）

跑 `python scripts/compliance_check.py <paper目录> [main.pdf]`，检查：
1. **摘要 ≤ 1 页**（PDF 第 1 页为摘要，页数校验）
2. **页码**：页脚中部、从摘要页 1 连续编号（检查 tex 的 fancyhdr 配置）
3. **图表全部居中**（每个 figure/table 环境内含 \centering）
4. **每条参考文献至少被 \cite 一次**（\bibitem 数 vs \cite 覆盖）
5. **页边距 ≥ 2.5cm**（tex 的 geometry 配置）
6. **页数**：摘要+正文 ≤ 当年官方上限（从 PDF 实际页数）
7. **匿名**：无姓名/学校/指导老师
8. **图表引用完整**：每个 figure/table 有 label 且正文有 \ref

## 四、合规检查清单（人工复核一遍）

- 页数：摘要 ≤1 页；摘要+正文 ≤ 当年官方上限；附录不计
- 公式：全部渲染、编号连续、正文有引用
- 图表：全部显示、居中、编号正确、正文有引用、图注中文
- 匿名：全文无姓名/学校/指导老师
- 参考文献：≥8 条、每条正文有 \cite、无官网/组委会条目、真实存在
- 文件：main.pdf 可打开、无缺字体；main.docx 可打开、无乱码、图片已嵌入
- 提交格式：按官方要求（PDF + 支撑材料）
