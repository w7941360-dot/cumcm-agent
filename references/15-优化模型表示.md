# 15 优化模型的标准表示方法

> 用途：当你把“设计/找最优”类问题转成标准数学规划时，用下面这种写法把目标 + 全部约束一次交代清楚。
> 这是数模论文（尤其 A 题工程优化设计、B 题离散调度）里的通用表达，评委一眼能看出“目标是什么、要满足哪些条件”。

## 一、标准模板

一个**带约束的优化问题（constrained optimization / mathematical programming）**写成：

```latex
\begin{equation}
\begin{aligned}
&\max_{x}\ f(x) \\
&\text{s.t.}\
\begin{cases}
g_1(x)\ge 0 \\
g_2(x)\le 0 \\
\vdots
\end{cases}
\end{aligned}
\end{equation}
```

- `\max`（或 `\min`）：最优化方向。
- `f(x)`：**目标函数**，`x` 是**决策变量**。
- `\text{s.t.}`：subject to，意为“受约束于”。
- 大括号 `{`（LaTeX `\begin{cases}`）：把一组约束**捆起来**，表示这些条件**同时成立**。

## 二、每个部分的含义

| 部分 | 记号 | 说明 |
|---|---|---|
| 目标 | `max/min f(x)` | 要优化什么（效率最大 / 成本最小 / 误差最小 …） |
| 决策变量 | `x`（可加下标 `x_i`、向量 `x=(x_1,…,x_n)`） | 我们可以“调/选”的量 |
| 约束 | `… ≥/≤/= …` | 可行域限制，常含几何、尺寸、资源、物理上限 |
| 硬约束 / 额定指标 | 如 `E≥60 MW` | 必须满足的**硬性**条件，**要进入搜索**而非事后判定 |
| 求和 | `∑` | 如 `∑_{i=1}^{N}`、`∑_{D=1}^{60}` |
| 下标范围 / 条件 | `i=1,…,N; j=1,…,N; i≠j` | 说明索引范围与“两两之间”等附加条件 |

## 三、写法规范（硬性）

1. **先理论推导，再定义变量与范围**：先说明决策变量是什么、取值区间（如 `2≤W≤8`、`0≤L_0≤350`），再写目标与约束。
2. **目标与约束必须同时给出**：只写目标不写约束，或只列约束不写目标，都算“模型不完整”。
3. **枚举本质不同的候选范式**：若问题有多种解法（如不同布局/不同建模路线），在正式模型前先列出并比较。
4. **硬约束一律进入搜索**：额定值/上限等必须作为约束写入模型（或作为可行性判定进入优化），不能只做事后校验。
5. **每条约束要有物理/工程来源**：写清“为什么有这条约束”（尺寸上下限来自题给、禁镜区、安全距离等）。

## 四、实例：2023 A 题定日镜优化模型（图片版本）

目标：最大化**单位镜面面积年平均输出热功率**

```
max   [ (1/60) ∑_{D=1}^{60} ( DNI_D · ∑_{i=1}^{N} A_i η_i ) ] / ∑_{i=1}^{N} A_i

s.t. {
      W_a ≥ W_b                         (镜宽 ≥ 镜高)
      2 ≤ W_a ≤ 8,  2 ≤ W_b ≤ 8         (镜宽/镜高尺寸上下限)
      2 ≤ h_i ≤ 6                       (安装高度上下限)
      0 ≤ L_0 ≤ 350                     (塔位偏移范围)
      L_{i,j} − W_a ≥ 5     i,j=1..N, i≠j   (相邻镜座中心距 ≥ 镜宽+5 m)
      X_i² + Y_i² ≤ 350²                (镜心在场区圆内)
      (X_i)² + (Y_i + L_0)² ≥ 100²      (镜心距塔 ≥ 100 m 禁镜区)
      (1/60)∑_{D=1}^{60}( DNI_D ∑_{i=1}^{N} A_i η_i ) ≥ 60 MW   (硬约束：额定功率)
      W_b/2 ≤ h_i                       (绕水平轴旋转不触地)
}
```

对照：
- **目标函数** = 年平均输出热功率 ÷ 总采光面积 → “单位面积功率最大”。
- `∑_{D=1}^{60}` 是 60 个时点（12 月 × 5 时刻），`1/60` 取平均；`∑_{i=1}^{N}` 对 N 面镜求和。
- `DNI_D`：第 D 时点法向直射辐照度；`A_i`：单镜面积；`η_i`：单镜光学效率。
- 约束把几何（尺寸/间距/场地）、工程（禁镜区/不触地）与**额定 60 MW 硬约束**一次性表达清楚。

## 五、在 skill 流程里何时用

- 步骤 1（赛题分析）全链路矩阵的“决策变量 / 硬约束 / 目标函数”列：用标准式写出来。
- 步骤 2（建模求解）MODELING_REPORT 第 0/几节：每个子问题先给“max + s.t. + 大括号”的标准模型式，再给出解法。
- 步骤 8（审计）`solution_audit.py --mode optimization`：会检查“额定/硬指标（rated_targets）”是否填、硬约束是否进入搜索，这与“硬约束必须进模型”一致。
