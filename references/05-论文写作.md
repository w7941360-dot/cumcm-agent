# 05 论文写作

> 本章结构、措辞规范已按 2025 国赛 A 题实战反馈（FEEDBACK.md 12 条）重构。写作前读模板 `templates/paper/main.tex`，其章节骨架即本章要求。

## 结构与章节规范

### 摘要（≤1 页，最重要）
- 结构：**背景段 + 每个问题各一段 + 关键词行**（无英文翻译）
- 每问段落**七要素**：
  1. 情形及与前问关系（基础/拓展）
  2. 建模（决策变量 + 目标函数）
  3. 算法点名 + 亮点
  4. **最优策略数值（6~8 位小数）**——如 1.391643、4.587300
  5. 结果
  6. 交叉验证/相对误差
  7. 附件说明（措辞：「其余数据见附件 result1.xlsx」）
- 若首问有数学前置结论（如区间连续性、判定简化引理），在摘要前给出证明要点
- ⚠️ **全程禁止「结果填入 resultX.xlsx」这类话术**（指"把某结果写进表格"的流程性表述，不是"数据见附件"）

### 问题重述
- 固定结构：一、问题重述 → 1.1 问题背景 → 1.2 问题提出
- 1.1 背景：物理原理/工程背景 + 实际价值 + 本文任务总述
- 1.2 提出：先总述已知条件，再**按本质归类**子问题（如：单机单弹求值→优化；多弹时序规划；多机空间协同；任务分配+资源调度）
- 全部用建模化措辞，禁写填表话术

### 问题分析
- 二、问题分析下设 **2.1~2.5 逐问分节**（不再整段混写）
- 每节**四步法**：①与前问关系 ②分步求解路线 ③本问特有难点 ④落点（本问建立什么模型）

### 符号说明
- **删除表名（caption）与表号、label**（正文不引用该表，删 label 安全）
- **每个符号单独一行**，禁止同一行放两个符号

### 模型准备（新增章，必须有）
- 顺序：**坐标系 → 态势可视化+观察分析 → 运动轨迹方程 → 关键判定条件（判定式）**
- 态势图是「观察→动机→算法」的起点，先画图再建模

### 模型建立与求解
- 每问设**副标题**（\subsection），不必每问单独大标题（\section）
- **建模四段式**：①情形及与前问关系 ②决策变量与目标函数 ③约束条件 ④建立公式
- **求解三段式**：①算法（点名+亮点） ②数值求解 ③结果与分析
- 数值结果保留 6~8 位小数

### 模型评价
- **保留模型检验**（灵敏度/稳定性/误差单独成章）
- **优点条数 > 缺点条数**
- 缺点用**「代价型」措辞**（如「以……计算代价换取……」「在……假设下适用」），不写自我贬低

### 参考文献
- 只保留 `thebibliography`，删除多余标题/官网/组委会条目
- **不少于 8 条学术文献**（期刊/会议论文）
- **每条至少被正文 `\cite` 一次**（用 compliance_check.py 自动检查）
- 引用必须真实存在，禁止编造（可用 arxiv/scholar 核实）

### 附录
- 标题「附录」**不编序号**（\section*）
- **A 支撑材料目录**：源程序、中间图表、结果数据清单
- **B 代码（Python）**：用**表格 + 行号**呈现，不直接粘贴大段代码

## 图表使用（插入时机与规范见 references/04-图表规范.md）
- 问题分析：每问用 1 张解题路径流程图，标注难点与突破点
- 模型准备：态势/坐标系图先行，**先画图再建模**
- 每问求解：算法流程图 + 核心结果图/表「三位一体」
- 模型检验/灵敏度：参数扰动曲线、热图、Tornado 图、误差/残差图
- 模型评价：优缺点用表格（如 SWOT 表）
- **图表节制**：图前有引导、图后有解释；正文解释文字明显多于图表；连续图表间必须有文字
- 结果段写法：① 计算设置/参数来源 → ② 解析基线 → ③ 放核心数值表格/图 → ④ 比较解析与数值一致性 → ⑤ 文字解释数值含义 → ⑥ 回答题目要求 → ⑦ 补误差/稳定性/局限
- 每张核心图表后必须有一段解释文字，至少回答：图表展示什么、关键数值/趋势、支撑哪句结论、是否与基线或验证结果一致


- A4 白纸，四边页边距 ≥ 2.5cm
- 摘要（含「摘要」标题与关键词）≤ 1 页
- 页码：页脚**中部**，阿拉伯数字**从摘要页 1 连续编号**
- 页眉：无多余内容；页号只在页脚中部
- 所有图表居中（\centering）；图注尽量中文
- 图内文字/图例间距合理，不拥挤不重叠

## 摘要五句公式（ARIS，辅助记忆）
1. 你完成了什么 2. 为什么重要且困难 3. 你怎么做的 4. 什么证据支撑 5. 读者该记住什么数字
（七要素是国赛逐问版，比五句更细，以七要素为准）

## 写作原则（句子层面）
- 主语谓语靠近；新信息放句末；上下文放句首；从旧到新；一个单元一个功能；动作放动词里
- 目标不是显得高深，而是让读者跟得上论证；假设先于公式；符号全篇一致、首次使用即定义
- 匿名：不出现姓名、学校、指导教师
