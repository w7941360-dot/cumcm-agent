> 已按 2026-08 国赛 A 题调研补充：**图表规划 → 插入时机 → 图/表选择 → 图注要点 → 图表节制**（吸收 MathModelAgent 与 cumcm-math-modeling-codex-skill 规范）；**支持专业彩色配色**与 **MATLAB 出图引擎**。

## 2026-08 实战补充：示意图必查清单
- 示意图可用**黑白或学术彩色**（风格统一、严谨细致）；若需黑白打印，用线型/标记/填充区分，不依赖颜色
- **箭头方向**必须与物理/运动/流程方向一致，出图后逐箭头核对（本次图 3、图 4(b)、图 7、图 14 都出过箭头指反）
- 图内文字字号要足够大（不低于 8pt，缩进论文后仍清晰）；文字不重叠、不超出图形外框
- 多子图（如 (a)(b)）逐子图检查箭头与文字
- 图注只写「展示什么 + 关键趋势/结果」；**禁止**写「该图支撑 XX 章节」「数据来源为 XX」；绘图脚本不得在论文中出现或声明

## 硬性要求
- **配色**：彩色或灰度均可。推荐**专业彩色**（色盲友好色板）；若需黑白打印评审，配色必须灰度可区分（用线型/标记兜底）。禁止默认彩虹渐变、高饱和荧光色
- 论文用图统一保存 PNG（≥300 dpi），LaTeX 与 Word 均直接用 PNG；不要求额外 PDF 版本
- 字号：坐标轴/图例 ≥ 8pt（打印后仍可读）；**源图字号偏大**，插入论文缩放后接近正文
- 每图必备：标题、轴标签含单位、图例、编号并在正文引用
- **所有图表在正文中居中（\centering）；题注单独一行并居中（\captionsetup{justification=centering}）；图注尽量中文**
- 禁止：3D 炫技图、无意义装饰、默认 matplotlib 风格直接上交
- 长类别标签换行，不要缩成小字硬塞

## 出图工具分界（数据图 vs 非数据图）—— 硬性规则
- **数据图**（由数值结果/数据决定）：结果曲线、热图/等高线、散点、收敛、灵敏度/参数扫描、误差残差、数据分布与预处理对比等 → 用 **matplotlib / MATLAB 从数据生成**（走步骤 4），图里数值必须**可溯源**（与 `resultN.xlsx` / 运行输出一致）。
- **非数据图**（不基于数据、属结构/原理/流程/示意）：全题技术路线图、工作机理示意图、坐标系/态势示意图、算法流程图、模型框架图、遮挡/几何示意图等 → 统一用 **Draw.io 生成**（走步骤 5，见 `references/14-DrawIO出图.md`）：生成**可编辑 `.drawio`** → 在 Draw.io 里人工改 → 导出 `SVG/PDF`（LaTeX）+ `PNG`（Word）。
- **判断标准**：图里的内容是否**直接由数据数值决定**（坐标轴是数据、点/线来自数组/结果文件）。是 → 数据图；否 → Draw.io 非数据图。

## 非数据图（Draw.io）：流程图 / 架构图 / 示意图
- 用 **Draw.io** 生成（流程见 `references/14-DrawIO出图.md`）：`python scripts/diagram_gen.py <清单.json> <图名.drawio>` 生成可编辑 `.drawio` → 在 Draw.io 里人工微调 → `drawio.exe --export --format svg|pdf|png` 导出。
- **矢量**（SVG/PDF）进 LaTeX，**PNG** 进 Word；保留 `.drawio` 源文件与清单 JSON 供后续改图。
- 架构/流程类图必须用外部图片文件（`\includegraphics`），不要内嵌 TikZ（保证 LaTeX→Word 可转换）。

## 配色规范（专业彩色）
- 首选**色盲友好**专业色板：Okabe-Ito（推荐）、ColorBrewer（Set1/Set2/Dark2）、Matplotlib `tab10`、期刊常用色（Nature/Science 风格）
- 热图/曲面连续色：Python 用 `viridis`/`cividis`/`magma`；MATLAB 用 `parula`/`turbo`。**禁止 `jet`/`rainbow`/`hsv` 彩虹色**
- 全篇统一一套色板，风格一致；多组对比用「颜色 + 线型/标记」**双编码**，保证灰度打印仍可区分
- **灰度检查**：出图后转灰度预览一遍（Python `plt.cm.gray` 渲染或 MATLAB `colormap(gray)`），确认不依赖颜色也能读懂
- 若最终提交要求黑白打印版：提供一版灰度兼容图（线型/填充/标记区分），并保留彩色版用于电子评审

## Python（matplotlib）统一样式（每次出图都套用）
- **中文字体**：`plt.rcParams['font.sans-serif']=['SimHei','Microsoft YaHei']` 与 `axes.unicode_minus=False`（否则负号显示为方块）
- **统一色板（Okabe-Ito 前 6 色）**：
  ```python
  plt.rcParams['axes.prop_cycle'] = plt.cycler(color=['#0072B2','#D55E00','#009E73','#CC79A7','#F0E442','#56B4E9'])
  ```
- **图注中文**：figure 文件内文字用中文（或英文标签 + 中文图注）
- **图内标注间距合理**：文字/图例/标注不拥挤不重叠；图例放在不遮挡数据的位置
- 线型区分（实/虚/点）+ 标记，多组数据用不同标记
- 坐标轴范围合理（不裁掉关键信息），刻度清晰
- **图文件统一存放 `figures/`**，命名 `fig_<内容>.png`（只需 PNG，≥300 dpi）；命名稳定小写：`fig_q1_trajectory.png`、`tab_q2_feasibility.csv`

## MATLAB 出图统一样式（本机 R2025b，与 Python 同等地位）
- 无头模式：`fig = figure('Visible','off')` + `exportgraphics(fig,'fig_xxx.png','Resolution',300)`（只需 PNG）
- 中文字体：`set(0,'DefaultAxesFontName','SimHei')`；无头缺字体时图内用英文标签 + 中文图注
- 统一色板（Okabe-Ito 六色）：`colors = [0.00 0.45 0.74; 0.85 0.33 0.10; 0.00 0.62 0.45; 0.80 0.47 0.65; 0.94 0.89 0.26; 0.34 0.71 0.91]`
- 热图/曲面：`colormap('parula')` 或 `turbo`；多组对比用「颜色 + LineStyle + Marker」双编码
- `set(gca,'FontSize',11)` 保证打印可读；详细函数与示例见 `references/10-MATLAB.md`

## 正确性规则（必须过，画图前先对着数据核）
- 被排除/标记的数据**绝不进汇总统计**：要么彻底不画，要么画成明显不同的点并在图例标注
- 题注和标题里的任何"声称"要**与每一组数据核对**：有反例就要限定范围
- **只有可比条件才并列**：不同样本量/口径/协议的数据不能当视觉同等
- **标 n 和固定了什么**：每个带汇总标记的面板注明样本量和单位
- **渲染后验证**：看 PDF/PNG 成品（不是脚本）——标签没被裁剪、图例没遮数据、打印尺寸下每个数字可读
- 每张图必须能对应一句论文结论：`图表 → 结论` 一一对应

## 风格规则（强默认，可商量）
- 配色、字体、装饰等可以按主题调整（满足上方配色规范即可）

## 图表规划（写代码/论文前先做）
- 每个**已求解子问题**默认至少 3 张图：① **工作机理示意图**（该问的物理机制/几何/能量流/光路/受力）② **算法流程图** ③ 核心结果图；有验证/误差/约束/敏感性分析时再加 ④ 检查图
- A 题（机制/几何/轨迹类）通常每问需要：**工作机理示意图 + 算法流程图** + 轨迹/曲线/布局结果图；几何类另加坐标系/对象示意图
- 完整论文默认图表集：
  - `fig_route_overview`：**全题技术路线图**/逐问流程图（放「问题分析」）
  - `fig_problem_overview`：题面对象、坐标系、数据流或任务范围示意（放「模型准备」）
  - `fig_mechanism_overview`：**全题工作机理示意图**——题目整体工作原理（能量流/光路/受力/信息流/时序），可并入 fig_problem_overview（放「模型准备」）
  - 每问：工作机理示意图 + 算法流程图 + 结果图（+ 验证/灵敏度图）
- 全题级图与每问级图允许合并：若某问的机理/算法与全题图重合，可共用一张并在图注/正文说明覆盖关系
- 优化/预测/评价/调度/仿真类，第三张「检查图」通常**不是可省项**；只有检查结果用 1 个很小的表格更清楚时才不画
- 只在「紧凑表格明显比图更清楚」时（如只有 3 个标量结果）才少画图，并在最终回复说明原因
- 跳过画图的合理场景仅限：纯符号推导（图会误导）、用户明确要求不画图

## 图表插入时机（按论文章节）
| 章节 | 插入什么 | 时机/位置 |
|------|----------|-----------|
| 问题重述/引言 | 技术路线图（可选）、场景/背景示意图 | 章节开头，交代整体任务 |
| 问题分析 | **全题技术路线图** + 解题路径流程图（每问 1 张，标注难点与突破点） | 节首放全题路线；每问分析段后放该问路线，2.2~2.6 逐问分节内（2.1 总体分析节首放全题技术路线图） |
| 模型准备（A 题必有） | 坐标系示意图、态势/场景俯视图+侧视图、**全题工作机理示意图** | **先画图再建模**：坐标系 → 态势/机理图 → 运动/控制方程 → 判定条件 |
| 模型假设 | 一般用三线表列假设（必要性+引用），不插图 | 假设小节 |
| 符号说明 | 符号三线表（按出现顺序，含单位，每符号一行） | 独立小节 |
| 数据预处理 | 数据分布图、缺失/异常值可视化、处理前后对比 | 预处理结论处 |
| 模型建立（每问） | **工作机理示意图** + 关键公式及推导过程 | 建模四段式的「建立公式/推导」前后；公式推导随文字展开，不依赖图 |
| 模型求解（每问） | **算法流程图**、核心数值结果图/表 | 求解三段式「算法点名」后放流程图；「结果与分析」处放结果图；解析 vs 数值用同轴曲线/误差曲线 |
| 模型检验/灵敏度 | 参数扫描曲线、热图、Tornado 图、误差/残差图、收敛性图 | 独立章节（模型检验），不塞进结果段 |
| 模型评价 | 文字分节陈述（优点/缺点/推广），不默认插表格 | 评价章节 |
| 附录 | 中间结果图表、大表、**每问求解/模型代码（注明代码名与逐行行号，不含生图代码）** | 正文只放关键图表，其余进附录/支撑材料 |

- 图表密度经验：正文（从模型建立算起）**每两页至少 1 张图表**；但正文解释文字必须**明显多于**图表内容
- 结果段顺序：给计算设置 → 解析基线 → **放核心数值表格/图** → 比较解析与数值一致性与偏差 → 文字解释 → 回答题目要求 → 补误差/稳定性

## 图 vs 表：何时用图、何时用表
- **用图**：趋势（折线）、分布（箱线/小提琴/直方图）、关系（散点/热力图）、对比（分组柱状/排序条形）、空间布局（地图/轨迹）、机制（流程图/示意图）
- **用表**：精确数值查询、多方案并列对比、约束可行性、符号说明、指标权重、误差指标汇总、排序前几名
- 判断：读者要「查精确值」用表；读者要「看出形态/趋势」用图；只有 3-5 个标量结果用表
- 同一结论**不要**同时用多张相似图 + 大表重复展示

## 图注要点（caption 模式）
- **题注排版**：题注单独一行并居中（\captionsetup{justification=centering}）；caption 文本内**不写「图 N：」/「表 N：」前缀**——编号由 LaTeX \caption 自动生成，手写前缀会造成「图 10: 图 10：…」图号重复
每张图 caption 写清楚：
1. 图展示了什么（对象/坐标/物理量）
2. 关键趋势或结果（一句话结论）
3. 若是验证图，说明验证含义
- ⚠️ **禁止**在图注里写「该图支撑 XX 章节」「数据来源为 XX」这类流程解释；为什么需要这张图由正文引导/解释文字交代
- 数据怎么得出的，在正文简要说明即可（如「由 XX 计算/仿真得到」「基于表 X」）；**不必**为每张图单独建立数据存储文件

例：「图 3 展示不同容量约束下的总成本变化。结果表明，容量提高到 260 件后，目标函数下降幅度明显变小，说明当前方案对小幅容量扰动较稳定。」
## 图表节制规则
- 正文只保留能支撑核心结论的图表；过程性表格、中间调试结果、大规模明细表放附录或 `tables/`
- 每张正文图表：**图前**有段文字说明为什么需要它、检验/回答什么问题；**图后**有段文字解释关键数值/趋势/对比/异常点，并回到题目要求、模型机制、基线比较或验证结论
- 连续 2-3 张以上图表中间没有文字 → 论文变成图集，必须删减图表或补足论证
- 表格不能替代文字推导，图像不能替代结果解释

## A 题典型图
- 态势/场景示意图（俯视图+侧视图）——模型准备的起点
- 坐标系/几何关系示意图
- 解曲面/热图/等高线（场分布）
- 时空演化序列
- 轨迹/路径/布局图（几何运动类：板凳龙、烟幕弹、无人机）
- 参数扫描/灵敏度曲线（带误差棒或区间带）、Tornado 图
- 搜索空间可行性图（理论上界 vs 额定指标，直观展示「是否可能达标」）
- 收敛性图（网格/步长 vs 误差）
- 模型 vs 实测数据对比、解析 vs 数值同轴对比
- 约束可行性检查图（覆盖区间并集、碰撞判定、工艺窗口等）
- 优化收敛曲线（目标/约束违反量 vs 迭代轮数，含可行性标记）
- 范式对比图（基线范式 vs 理论推导范式在同一精度/预算下的同轴对比）
- 约束边界/裕量图（最优解距硬约束边界的裕量 Δ，标注安全区间）
- 流程图/架构图（步骤5）：全题技术路线、全题工作机理、每问算法流程/模型框架
- 公式推导过程（文字，非图）：逐步推导、标注依据，禁止只贴最终公式
