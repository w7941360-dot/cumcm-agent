# 02 建模选型

## 模型分层（A 题优先机理）
- 机理模型：守恒方程 → ODE/PDE → 数值求解
- 参数辨识：最小二乘 / 极大似然 / 贝叶斯 / 网格搜索；评价拟合优度
- 数据驱动（仅辅助）：回归、插值、机器学习 —— 机理不明确时补充，A 题不要全程黑箱
- 优化：含决策/设计变量时 → 线性规划/非线性规划/启发式

## A 题共同规律
- A 题优先是**机制题**，不是模型名堆砌题：先建立坐标、时间、单位和物理量，再选算法
- 几乎都需要「**解析基线 + 数值仿真 + 约束优化**」三层结构
- 图表要展示机制：曲线、轨迹、空间布局、约束可行性、优化前后对比
- 得分点通常在「模型是否贴合物理过程」和「结果是否可验证」，不是算法复杂度

## A 题默认解题顺序
1. 物理对象拆解：明确运动对象、控制变量、状态变量、观测量和目标量
2. 坐标与时间轴：统一坐标系、时间零点、单位、方向和边界
3. 解析基线：写出简化情形下的公式或可手算方案
4. 仿真模型：把状态演化、几何关系或能量转换写成可复现代码
5. 优化模型：定义决策变量、目标函数、硬约束和软约束
6. 可行性检查：检查速度、温度、功率、伸缩量、碰撞、覆盖或遮挡等约束
7. 敏感性分析：扰动关键物理参数和优化变量，观察结果稳定性
8. 论文表达：按「物理机制 → 数学表达 → 算法求解 → 约束检查 → 结果解释」顺序写

> ⚠️ 含**硬性额定指标 + 布局/设计变量**的优化题（如 2020 工艺窗口、2021 反射面、2023 定日镜、2025 时序覆盖），不能只按上面顺序线性走完就交付：必须先读下方「优化问题的求解治理」，把步骤 5~6 从"事后检查"升级为"搜索前门禁 + 搜索中硬约束"。

## 优化问题的求解治理（含额定指标/设计变量的题必读）
> 通用方法论，适用于布局、结构、容量、时序、工艺窗口等一切"硬指标 + 设计变量"优化题。详细抽象案例见 `references/11-带硬指标的设计优化.md`。

### 1. 搜索空间设计：先理论推导，再定义变量
- **先推导必要条件、几何/物理关系与可行上界，再定决策变量与取值范围**；禁止无说明地使用经验默认值
- 每个变量范围必须注明推导来源（几何避挡、守恒律、工艺窗口、材料极限等）
- 至少提出**两个本质不同的候选范式**（例：密排基线 vs 无遮挡/无阻塞推导布局；单机基线 vs 多机协同）
- 编程前必须给出**至少一个由全模型验证的可行种子**，或显式声明"当前范式尚不保证含解"
- 若理论功率/性能上界低于额定目标，**立即否决该搜索空间**，不得继续扫描
- 决策变量全集不只是位置/尺寸/高度：还包括间距、分区边界、数量及其随空间（半径/距离/时间）的变化关系

### 2. 硬约束必须进入搜索，禁止只做事后判定
- 统一采用**可行性优先**表达：先最小化约束违反量，只有 `v(x)=0` 后才比较效率/成本目标：
  \[
  v(x)=\max\left(0,\;P_{\mathrm{rated}}+\Delta_P - P_{\mathrm{full}}(x)\right)
  \]
- 候选排序分"可行 / 不可行"两层；不可行候选永远排在可行候选之后，即使其目标更优
- `ΔP`（安全裕量）根据模型误差与交叉验证误差设定，写入求解验收契约
- 硬约束不能只在 refine 后生成 `feasible=False` 就完事；**无可行解时必须返回搜索空间重定义**
- 结果文件不得由不可行候选生成

### 3. 代理目标与全模型一致性（保真度门禁）
- 列出**全模型物理项清单**，说明代理保留/近似/省略了哪些项
- 在近区/中区/外圈、不同关键位置及目标边界附近**分层采样**，用全模型对代理校准
- 默认门槛（按题可调，写入求解验收契约）：排序相关系数 ≥0.9；校准集中"代理判可行、全模型不可行"的**假阳性 = 0**
- 若省略某物理项使目标变化超过 2%，或改变可行/不可行判定，该项**不得从代理中删除**
- top-K、接近额定功率边界的候选和多样性候选必须进入全模型复核
- 若代理校准失败：重构代理，或直接缩小搜索空间后全模型求解

### 4. 多阶段/变规格问题（自由度扩展）
- 后一问放开决策自由度时，必须**显式列出相对前一问新增的自由度**
- 采用分区或分段函数表达随空间/位置变化的规格（示例：`w(r)`、`h(r)`、`z(r)`）
- 将**分区边界、各区规格**一并作为决策变量；首轮用 3~5 个环带/分区，避免逐点变量导致维数爆炸
- 候选规律（如"近塔小镜、远塔大镜、远镜升高"）只是假设，**必须用全模型验证**
- 若只优化高度而尺寸始终统一，必须标明这是**受限子模型**，不能直接宣告完成完整问题

## 三类高频方法包

### 工程过程控制（2020 炉温曲线、2022 波浪能）
- 基线：一阶惯性、分段线性、能量守恒或简化微分方程
- 主模型：ODE/差分方程、参数拟合、数值积分、单/多参数优化
- 必查：参数单位、边界条件、采样间隔、峰值、持续时间、平均功率
- 常见错误：只拟合曲线不解释物理量；优化结果违反工艺窗口或功率定义

### 几何光学与曲面设计（2021 FAST、2023 定日镜场）
- 基线：理想几何曲面、单点反射、无遮挡效率
- 主模型：坐标变换、曲面拟合、光线追踪、遮挡阴影、布局优化
- 必查：坐标系、法向量、反射定律、角度单位、边界范围、机械约束
- 常见错误：没有统一坐标系；只算效率不查遮挡或伸缩量可行性

### 轨迹覆盖与避碰优化（2024 板凳龙、2025 烟幕干扰弹）
- 基线：单对象轨迹、单时间段覆盖、规则速度方案
- 主模型：运动学方程、碰撞/遮蔽判定、区间合并、多阶段优化、启发式搜索
- 必查：时间离散步长、速度范围、间隔约束、覆盖半径、碰撞距离、区间重叠
- 常见错误：用离散采样直接声称最优；遮蔽/碰撞判定没有几何解释
- 多弹/多对象问题：单对象最优只能作基线；必须最大化并集覆盖并惩罚重叠；时序间隔等是**硬约束**不是后处理格式问题；搜索方案写「固定随机种子得到的可行优选方案」，不写「已证明全局最优」

## A 题数值方法库
| 问题 | 方法 |
|------|------|
| ODE 初值问题 | RK4 / scipy.solve_ivp |
| 一维抛物型（热传导/扩散） | 隐式差分（Crank-Nicolson） |
| 双曲型（波动/对流） | 特征线 / 迎风格式，注意 CFL 条件 |
| 椭圆型（稳态场） | 有限差分松弛 / 直接解线性系统 |
| 复杂几何/材料 | 有限元（如 FEniCS）或简化几何 |
| 随机过程 | 蒙特卡洛、随机微分方程 |
| 空间离散 | 有限差分 / 有限体积，检查稳定性与收敛 |
| 单目标连续优化 | scipy.optimize / fmincon（MATLAB） |
| 全局优化（多峰/平台效应） | 粒子群 / 遗传 / 模拟退火 / 多起点 |
| 约束优化 | 可行性优先外循环 + 罚函数 / SLSQP / 序列二次规划 |

## 必做分析（A 题得分关键）
1. **灵敏度分析**：关键参数 ±10%~±50% 扰动，观察结果变化；单参数扫描或 Sobol
2. **稳定性/收敛性**：网格加密、时间步长减半，验证结果不漂移
3. **模型验证**：与解析解对照 / 与题给数据对比 / 极端情形检验
4. **量纲一致**：每个方程检查单位
5. **候选物理模型的可行性敏感性**（优化题必做）：对截断、阴影、遮挡等存在多种合理模型的模块，在近区/中区/远区及典型季节（或典型工况）抽样比较：
   `物理假设｜计算成本｜独立验证误差｜年均(总)性能差｜是否改变硬约束判定`
   若模型 A/B 使结果从不可行变为可行，则：依据真实受光/受力/工况几何选择模型；用蒙特卡罗或另一套独立方法验证；把模型误差转换成功率/性能安全裕量；**禁止单纯选择"更保守""计算更快"或"刚好能达标"的模型**

## 建模原则
- 假设明确、可辩护；先简后繁，先保证可解再逼近真实
- 每个模型写清：输入、输出、参数、适用范围
- 明确模型局限性（评审常考）
- 优化题额外写清：搜索空间来源、范式对比、硬约束与裕量、可行种子/上界、代理保真度、预算使用（写入 `MODELING_REPORT.md` 第 0 节）
