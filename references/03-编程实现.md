# 03 编程实现

## 引擎选择（步骤3 开始时向用户确认）
- 三选一或混合：**MATLAB（本机 R2025b）** / **Python** / **混合**（如 Python 预处理 + MATLAB 重计算）
- **求解与出图引擎保持一致**：MATLAB 出图用 `exportgraphics`，Python 出图用 matplotlib；图表规范见 `references/04-图表规范.md`、MATLAB 细节见 `references/10-MATLAB.md`
- 引擎不影响交付：结果统一写 CSV/mat，论文数字统一走步骤8 证据预检

## 工程规范（Python）
- Python 3 + numpy/scipy/pandas/matplotlib；结构清晰、函数化、注释关键公式出处
- `code/` 下：`main.py`（一键复现主流程）+ `utils.py`（通用函数）+ 各模型脚本
- 固定随机种子 `np.random.seed(0)`，结果与图表可复现
- 数值计算保存中间结果（npy/csv），避免重复跑长任务

## 工程规范（MATLAB）
- `code/` 下：`main.m`（一键复现主流程）+ 分模型 `.m` 脚本
- 固定随机种子 `rng(0)`，结果与图表可复现
- 无头调用：`matlab -batch "run('main.m')"`，冷启动约 20~40s，**多个小任务合并进一个 .m 一次跑完**
- 详细函数/工具箱/出图见 `references/10-MATLAB.md`

## 数值实现要点
- ODE/PDE 求解：选稳定格式，检查 CFL/收敛；scipy.integrate 设 rtol/atol 并验证（MATLAB：ode45/ode15s/pdepe）
- 线性系统：注意条件数，病态时用正则化或提高精度
- 大量实验：写循环 + 进度日志 + 结果汇总表

## 结果可信度校验（每项都过）
1. **Sanity**：数量级合理吗？单位对吗？极端输入下行为合理吗？
2. **Consistency**：结果内部自洽（守恒量守恒、边界条件满足、不同方法结果一致）
3. **Physical**：物理约束满足（非负、有界、能量/质量守恒）
4. **Prediction**：外推一段是否合理？参数扰动方向是否符合直觉
5. **Evaluation**：与数据/解析解对比的误差指标（MAE/RMSE/相对误差）
