# 06 编译与合规（PDF + Word）

> 产出两个文件：`paper/main.pdf`（参赛提交）+ `paper/main.docx`（Word 版）。写论文用 LaTeX（`main.tex`），Word 用 pandoc 从 LaTeX 导出，PDF 编译见下方方案 A/B。

## 一、Word 导出（pandoc：LaTeX → docx）— 推荐，已实测可用

### 工具解析（按顺序找 pandoc）
1. PATH 上的 `pandoc`（如 Anaconda 自带 2.12，实测中文+公式转换成功）
2. Modex 内置 runtime（仅当已安装 Modex）：`D:\modex\Modex-MH-Agent\runtime\pandoc\pandoc.exe`（3.7）
3. 都没有 → 提示安装：`winget install JohnMacFarlane.Pandoc` 或 `conda install -c conda-forge pandoc`

### 命令
```
cd paper
pandoc main.tex -o main.docx --resource-path=. --resource-path=../figures
```
- `--resource-path`：让 pandoc 能找到 figures/ 下的图片（图片被嵌入 docx）
- 数学公式自动转成 Word 原生公式（OMML），可在 Word 里编辑

### 转换注意事项（重要）
1. **TikZ/PGF 内联图不转换**：pandoc 无法渲染 TikZ。架构图/流程图必须用外部图片文件（步骤5 已约束用 `\includegraphics` 引用 drawio/mermaid/HTML 导出的矢量图）
2. **自定义命令/宏可能丢失**：尽量只用标准 LaTeX（amsmath、booktabs、graphicx、ctex）；自定义 `\newcommand` 若影响内容，先在 tex 里展开
3. **页数会变**：Word 排版与 PDF 不同，导出后必须在 Word 里单独核对页数上限
4. **中文字体**：pandoc 导出的 docx 用 Word 默认字体；若学校模板有字体要求，导出后套模板调整
5. **附录/目录**：如需目录，加 `--toc`；附录程序代码块建议直接放代码文本

### 导出后检查
- [ ] main.docx 能正常打开、无乱码
- [ ] 公式显示为可编辑的 Word 公式（不是图片/纯文本）
- [ ] 图片都在、位置合理
- [ ] 在 Word 中核对：页数 ≤ 官方上限、匿名、图表编号引用完整

## 二、PDF 编译（两个方案）

### 方案 A：Overleaf（推荐，零安装、对中文/ctex 最稳）
1. 打开 overleaf.com，新建项目，上传 `paper/main.tex` + `figures/` 全部文件
2. 菜单 → 编译器选 **XeLaTeX**（中文必需）
3. 编译通过后下载 `main.pdf` 放回 `paper/`
4. 检查日志：undefined references、missing characters、严重 overfull

### 方案 B：本地 xelatex（需有可用的 TeX）
- 工具解析（按顺序找 xelatex）：
  1. PATH 上的 `xelatex`
  2. Modex 内置 runtime：`D:\modex\Modex-MH-Agent\runtime\texlive\miktex\bin\x64\xelatex.exe`
- ⚠️ **Modex 内置 MiKTeX 常见坑**：它是"未初始化"状态，直接跑会报 `fresh TeX installation, please finish the setup`。
  解决：
  1. 先让 Modex 应用完成一次 LaTeX 安装（它首次启动会自动装 MiKTeX）；或
  2. 运行 Modex 目录下的 `runtime\miktex-setup.exe` 完成初始化；或
  3. 干脆用方案 A（Overleaf），省事
- 命令：`xelatex -interaction=nonstopmode main.tex`（跑 2-3 遍解决交叉引用）
- 都没有 TeX → 提示用户装 MiKTeX/TeX Live，或用方案 A

## 三、合规检查清单（PDF 与 Word 各查一遍）

- 页数：摘要 ≤1 页；摘要+正文 ≤ 当年官方上限；附录不计
- 公式：全部渲染、编号连续、正文有引用
- 图表：全部显示、编号正确、正文有引用
- 匿名：全文无姓名/学校/指导老师
- 文件：main.pdf 可打开、无缺字体；main.docx 可打开、无乱码
- 提交格式：按官方要求（一般 PDF + 程序打包）
